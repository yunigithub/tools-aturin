Download Semua (ZIP) memakai tool yang sedang aktif untuk semua gambar, khusus tool kompres, resize, convert, watermark, dan hapus metadata.

Pilih Tool

Kompres Gambar

Buat ukuran file lebih kecil. Untuk JPG dan WebP, kualitas menentukan ukuran. PNG tidak memakai kualitas.

Resize Gambar

Convert Gambar

Ubah format gambar aktif. Input yang didukung browser: JPG, PNG, WebP, AVIF, GIF, BMP, dan SVG (SVG dirasterisasi dulu ke ukuran 1024 px).

Crop Gambar

Seret kotak di atas gambar pratinjau untuk memilih area. Seret sudut untuk mengubah ukuran, seret tengah untuk memindah.

Rasio:

Rotate dan Cermin

Perubahan langsung diterapkan ke gambar aktif.

Watermark

Sensor Gambar

Seret kotak di atas gambar pratinjau pada area yang mau disensor. Cocok untuk nomor KTP, alamat, dan wajah.

Belum ada kotak sensor.

Hapus Background

Menghapus background foto dengan AI yang jalan di perangkatmu. Pertama kali memakai tool ini, model AI sekitar 40 MB akan diunduh dan disimpan di browser, jadi butuh internet dan sedikit waktu. Setelah itu prosesnya cepat dan tidak perlu upload foto ke mana pun. Hasilnya PNG transparan.

HEIC ke JPG

Ubah foto HEIC dari iPhone menjadi JPG yang bisa dibuka di mana saja. Kalau file yang dipilih bukan HEIC, tool ini akan memberi tahu.

Pas Foto

Crop gambar ke ukuran pas foto pada 300 dpi. Kalau gambar punya latar transparan (misalnya habis hapus background), warna latar di bawah akan terlihat.

Warna latar:

Lembar 4R campuran berisi 8 foto: 2 foto 4x6, 2 foto 3x4, dan 4 foto 2x3 dalam satu lembar 1200 x 1800 px siap cetak. Lembar isi penuh mengisi lembar dengan satu ukuran yang dipilih.

Ganti Background Pas Foto

Tool ini menghapus background foto dengan AI dulu, lalu menaruh fotomu di atas warna solid pilihan. Cocok untuk pas foto dengan latar merah atau biru.

Warna latar:

QR Code Generator

Gabung Gambar

Menggabungkan semua gambar yang sudah dipilih di atas. Butuh minimal 2 gambar.

Ukuran Sosmed

Pilih preset, lalu terapkan. Mode isi penuh memotong tengah gambar, mode muat memberi latar supaya seluruh gambar terlihat.

Belum ada preset dipilih.

Hapus Metadata

Menyimpan ulang gambar lewat canvas akan membuang metadata seperti lokasi GPS, detail kamera, dan tanggal foto. Gambar tetap sama secara visual, hanya datanya yang dibersihkan.

Favicon Generator

Membuat favicon dari gambar aktif: PNG ukuran 16, 32, dan 48 px, plus file favicon.ico. Semua diunduh jadi satu ZIP.

Tanda Tangan Transparan

Ubah foto tanda tangan di atas kertas putih menjadi PNG transparan. Piksel yang terang jadi transparan, goresan tinta tetap terlihat. Atur threshold kalau hasilnya terlalu pudar atau masih ada sisa kertas.

Laporan Foto A4

Susun foto beserta judul dan caption di halaman A4. Tombol Print akan membuka dialog cetak browser, pilih Save as PDF untuk menyimpan sebagai PDF.

Upscale Gambar

Naikkan resolusi gambar 2x atau 4x. Mode canvas cepat dan selalu jalan. Mode AI (ESRGAN) lebih tajam untuk foto, tapi perlu mengunduh model dan memori besar, jadi paling baik untuk gambar di bawah 2 MP.

SVG ke PNG/JPG/WebP

Ubah file SVG menjadi gambar raster. Kalau SVG tidak punya lebar dan tinggi, lebar output di bawah yang dipakai, dan tinggi mengikuti aspek dari viewBox.

EPS ke PNG/JPG

File EPS, AI, dan PSD dibuka lewat Photopea yang berjalan di browsermu. Photopea butuh internet untuk memuat aplikasinya, tapi file diproses di perangkatmu dan tidak di-upload ke server.

Catatan: ukuran hasil mengikuti rasterisasi Photopea saat membuka file. Kalau diisi, lebar hasil diatur setelah file dibuka, tinggi mengikuti aspek aslinya.

Edit di Photopea

Kirim gambar aktif ke editor Photopea, edit langsung di sana, lalu ambil hasilnya kembali ke sini. Photopea butuh internet untuk memuat aplikasinya.

Catatan privasi: tool lain di halaman ini memproses file sepenuhnya lokal tanpa pihak ketiga. Jalur Photopea memuat aplikasi Photopea dari photopea.com dan file diproses oleh kode Photopea di browsermu (tetap di perangkat, tidak di-upload ke server).

Upscale Image

Raise the image resolution 2x or 4x. Canvas mode is fast and always works. AI mode (Real-ESRGAN) is sharper for photos, but the first run downloads the model (about 5 MB) and the AI engine (about 30 MB on CPU, less on WebGPU), then both are cached. It works best for images under 2 MP. WebGPU is fastest; without it the CPU fallback is slower, especially on weak phones.

EPS to PNG/JPG

EPS, AI, and PSD files open through Photopea running in your browser. Photopea needs internet to load its app, but your file is processed on your device and never uploaded to a server.

Note: the result size follows how Photopea rasterizes the file when opening it. If you enter a width, the result width is set after the file opens, and the height follows the original aspect.

Edit in Photopea

Send the active image to the Photopea editor, edit it right there, then bring the result back here. Photopea needs internet to load its app.

Privacy note: the other tools on this page process files fully locally with no third party. The Photopea path loads the Photopea app from photopea.com, and your file is processed by Photopea code in your browser (it stays on your device, it is not uploaded to a server).

About Image Tools

Image Tools is a free set of image tools that runs entirely in your browser. Compress images, resize them, convert formats, remove backgrounds, make passport photos, and more, all without installing anything. Your files never leave your device, so your photos stay private.

Frequently Asked Questions

Do my images leave my device? No. Everything runs in your browser, and your files are never uploaded to a server.

Is it really free? Yes. Every tool is free, with no sign-up and no limits.

Which formats are supported? JPG, PNG, WebP, AVIF, GIF, BMP, HEIC, and SVG, plus EPS, AI, and PSD through Photopea.

Does it work on phones? Yes. The page is mobile-first, so you can use every tool from your phone browser.
